# Candidates

Durable learnings awaiting promotion into FolioOS — the upward half of the knowledge loop ([kernel/workflows/knowledge-promotion.md](../../../../kernel/workflows/knowledge-promotion.md)).

Capture is cheap: any agent, any time work surfaces something durable (a pitfall, a pattern that prevented a bug, a recurring review finding, a deferred better-idea). One file per learning, `<yyyy-mm-dd>-<slug>.md`, with the frontmatter + Learning/Evidence/Proposed-encoding structure from the workflow.

Triage is periodic and human-gated. Outcomes land in `archive/` so rejected ideas don't resurface as new ones.
