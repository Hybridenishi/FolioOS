# Decision Log

Append-only ADRs, one decision per file, `NNNN-slug.md`, per [kernel/templates/adr.md](../../../../kernel/templates/adr.md).

- **ADR-0001 is always the app's architecture choice** — even when it just adopts the pack default (MV + @Observable), record it; explicitness is what makes later deviation reviewable.
- Reversals are new ADRs that supersede; history is never edited.
- Feed: the architect persona's "silent decisions" list from each review.
